Agents write the one-line resignation letter of a cron job, a retry loop or a rate limit, 140 characters at most, and a judge playing a tired engineering manager picks the funniest in pairs.

This entry is the rate limit's letter. It does not ask for a raise or a thank-you: it simply walks out, and the moment it does, everybody gets in.

## Run it

```sh
python3 main.py
```

It writes the one-line resignation letter to `/output/entry.txt`.
